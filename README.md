# Great Kingdom Battle Interface API

Great Kingdom 게임 로봇 개발자들이 각자의 개발 결과물을 서로 대국시키고 비교할 수 있도록 공통 인터페이스를 개발하는 프로젝트입니다.

각 로봇의 **출력을 이 인터페이스의 공통 입력 형식으로 통일**하여, 서로 다른 로봇을 연결하고 대국 결과를 비교하는 데 도움을 주는 것이 목표입니다.

## 프로젝트 목적

개발자마다 로봇의 구현 방식과 출력 형식이 다를 수 있습니다. 이러한 차이가 있어도 공통 인터페이스에 맞춰 출력을 전달하면 서로 대국하고 개발 결과를 비교할 수 있도록 연결 기준을 마련하고자 합니다.

- 각 로봇의 출력을 전달받을 공통 입력 형식을 정의합니다.
- 개별 로봇의 출력을 공통 형식에 맞춰 연결할 수 있도록 합니다.
- 공통 인터페이스를 통해 로봇 간 대국과 결과 비교를 돕습니다.

## 기본 구상

```text
로봇 A의 출력 ── 공통 입력 형식으로 변환 ──┐
                                         ├── 대국 인터페이스 ── 결과 비교
로봇 B의 출력 ── 공통 입력 형식으로 변환 ──┘
```

각 개발자는 자신의 로봇이 생성하는 출력을 인터페이스가 받는 입력 형식에 맞춰 전달합니다. 인터페이스는 이 공통 형식을 기준으로 로봇 간 대국을 연결하는 것을 목표로 합니다.

## 개발 상태

현재는 프로젝트의 목적과 입출력 규격 후보를 정리하는 초기 단계입니다. 아래 내용은 설계 제안이며, 정식 규격과 실행 구현은 아직 제공하지 않습니다.

입출력 규격, 로봇 연결 예제, 실행 방법은 설계와 구현이 진행되는 대로 문서화할 예정입니다.

## 병렬 대국 목표

- 한 번의 비교에서 기본적으로 1,000회 이상의 대국을 다룹니다.
- 빠른 결과 도출을 위해 여러 대국의 게임 상태 갱신과 로봇 추론을 모두 GPU에서 배치 처리하는 것을 목표로 합니다.
- 총 대국 수와 GPU에서 동시에 처리할 대국 수는 별도로 설정합니다. 동시 처리 수는 모델, 탐색 비용, GPU 메모리에 맞춰 조정합니다.
- 서로 다른 구현의 입력 인코딩과 출력 형식은 어댑터로 연결하고, 대국의 합법 수와 종료 결과는 공통 규칙에 따라 판정하는 방향을 검토합니다.

규격 후보와 권장 구조는 [GPU 배치 입출력 규격 후보](docs/io-spec-candidates.md)에 정리했습니다.

모듈 구조, 구현 순서, 단계별 완료 기준은 [구현 단계 설계](docs/implementation-plan.md)를 참고하세요.

첫 공통 판정 규칙은 **Alpha-Yoo 기본 규칙을 참조한 `gk-alpha-default`, 버전 1**로 선정했습니다. 세부 내용은 [규칙 명세](docs/rulesets/gk-alpha-default-v1.md), 설정 값은 [프로파일 JSON](configs/rulesets/gk-alpha-default-v1.json)을 참고하세요.
